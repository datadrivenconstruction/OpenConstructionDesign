The fastest way to get going is the interactive "First steps" tutorial ([[cmd:help.tutorial]]): six short lessons - interface, walls, doors and windows, wall by room outline with undo, levels and a roof, dimensions and views. To look at a finished model first, open the sample two-storey house ([[cmd:help.sample]]).

Help is always at hand: `F1` opens the topic for the active tool, the selected element or the current view.

## steps
1. Start [[cmd:help.tutorial]] and follow the prompts - steps are checked automatically.
2. Draw walls: type `WA` ([[cmd:arch.wall]]), click points, `Enter` ends the chain, `Esc` leaves the command. Details: [[topic:walls]].
3. Place a door and a window: `DO` and `WN`, hover a wall and click ([[topic:doors_windows]]).
4. Add a level and a roof ([[topic:levels]], [[topic:roofs]]); floor and room tools are planned ([[topic:floors]], [[topic:rooms_areas]]).
5. Open 3D (`Ctrl+3`) and a section ([[topic:views_3d]], [[topic:sections_elevations]]).
6. Look at the schedule table in the "Model + table" interface (`Ctrl+Alt+5`): [[topic:schedules]]; exchange files: [[topic:export]].
7. Made a mistake? `Ctrl+Z`. Every action can be undone, see [[topic:undo_history]].

## keys
- `F1` - contextual help
- `Ctrl+K` - palette: type any word from a command name
- `Esc` - step back or leave the command
- `Ctrl+Z` / `Ctrl+Y` - undo and redo

## tips
- Commands are invoked by two Latin letters typed in a row within 0.8 s (`WA`, `DO`); on other keyboard layouts the same physical keys work.
- The sample house is a good place to study the schedule table and queries: it has every category of elements.
- What changed in this version: [[cmd:help.whats_new]].
