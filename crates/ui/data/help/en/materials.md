# Materials and object styles
@tags material, object styles, color, hatch
@context mgr.materials mgr.object_styles
@commands mgr.materials mgr.object_styles view.filters
@see wall_layers visibility

A material sets the colour and pattern of a layer; an object style sets the lines and fill of a category in views.

**Not available yet:** the materials list (`mgr.materials`), object styles (`mgr.object_styles`) and visibility filters (`VV`). The ribbon buttons of these commands are inactive.

## steps
1. The project materials list ([[cmd:mgr.materials]]) is planned; today materials are assigned through layers of a type ([[topic:wall_layers]]).
2. Assign a material to a layer in a type ([[topic:wall_layers]]).
3. Line weights and colours per category ([[cmd:mgr.object_styles]]) are planned.
4. Visibility filters ([[cmd:view.filters]]) are planned.
5. Form faces get materials with "Paint" ([[cmd:mass.paint]]).
6. Check the result in plan, section and 3D: hatches depend on scale.

## keys
- `Ctrl+Z` - undo

## tips
- One material, many layers: change it in one place.
