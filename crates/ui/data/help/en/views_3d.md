# The 3D view
@tags 3D, shadows, display style, realistic, shaded
@context view.3d view.style view:3d
@commands view.3d view.style view.thin_lines view.section_box
@see navigation_3d section_box big_files

The 3D view shows the whole model at once with shadows and correct glass sorting.

**Not available yet:** thin lines and 3D version compare. The ribbon buttons of these commands are inactive.

## steps
1. Open 3D: `Ctrl+3` ([[cmd:view.3d]]).
2. Control the camera with the mouse ([[topic:navigation_3d]]).
3. Visual style: `VS` ([[cmd:view.style]]): shaded, consistent colors, hidden line, wireframe, X-ray. Category visibility in 3D: [[cmd:view.vg_3d]]; the view can be saved ([[cmd:view.save_3d]]).
4. Limit the model with a section box ([[topic:section_box]]) to look inside.
5. Selection, grips and editing in 3D work as in plan.

## keys
- `Ctrl+3` - 3D view
- `F` - fit

## tips
- On a heavy model use a section box or isolate the part you need ([[topic:big_files]]).
