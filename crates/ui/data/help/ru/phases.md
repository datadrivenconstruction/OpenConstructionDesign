# Стадии и снос
@tags стадии, снос, реконструкция, существующее, phases, demolish, renovation
@context mgr.phases mod.demolish
@commands mgr.phases mod.demolish view.filters
@see visibility schedules

Стадии описывают жизнь проекта: существующее, снос, новое. Каждый элемент помнит, на какой стадии создан и когда снесён, а вид показывает выбранную стадию.

## steps
1. Откройте [[cmd:mgr.phases]] (`PH`): окно «Стадии»: порядок стадий (двойной щелчок: переименовать), кнопка «Текущая» (стадия новых элементов), добавление стадии.
2. В блоке «Стадия и фильтр видов» задайте стадию и фильтр для плана: без фильтра, итог стадии, обмер (существующее), демонтаж, проект, только новое, все стадии; есть и пресеты плана «Обмер», «Демонтаж», «Проект».
3. Новые элементы получают текущую стадию.
4. Демонтаж: выберите элементы и нажмите `DX` ([[cmd:mod.demolish]]): они помечаются снесёнными в текущей стадии; окно перечисляет их и позволяет вернуть.
5. Что показано, решает фильтр: обмер показывает существующее, демонтаж: снесённое, проект: результат.
6. Таблицу спецификации можно ограничить по стадии ([[topic:schedules]]).

## keys
- `PH`: стадии, `DX`: снести

## tips
- Снос не удаляет элемент: его можно вернуть и учесть в сметах сноса.
