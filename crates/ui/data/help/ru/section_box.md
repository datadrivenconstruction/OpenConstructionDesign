# Секущий бокс
@tags секущий бокс, обрезка, внутри, section box, clip
@context view.section_box
@commands view.section_box view.3d mod.isolate
@see views_3d big_files navigation_3d

Секущий бокс обрезает 3D-вид прямоугольным объёмом: видно только то, что внутри. Это лучший способ заглянуть в здание и разгрузить тяжёлую сцену.

## steps
1. Откройте 3D (`Ctrl+3`).
2. Нажмите `BX` ([[cmd:view.section_box]]): команда работает как переключатель; бокс охватывает модель с запасом 0,3 м.
3. Тяните грани бокса (ручки), чтобы сдвигать плоскости сечения.
4. Вращайте камеру, чтобы увидеть срез с нужной стороны.
5. Повторный вызов выключает бокс и возвращает всю модель.
6. Чтобы показать один уровень, подведите верхнюю и нижнюю грани к его уровню.
7. Бокс по выбранным элементам: [[cmd:view.section_box_fit]]; заливка разреза на гранях: [[cmd:view.section_caps]]; 3D-вид одного уровня: [[cmd:view.level_3d]].

## keys
- `BX`: секущий бокс вкл. / выкл.
- `Ctrl+3`: 3D
- `F`: вписать

## tips
- Бокс влияет только на показ, модель не меняется и в спецификациях остаётся целиком.
- На больших моделях ограничение объёма резко ускоряет отрисовку ([[topic:big_files]]).
- Бокс можно сочетать с изоляцией ([[topic:visibility]]).
