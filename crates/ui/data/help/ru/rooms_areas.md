# Помещения, разделители, зоны
@tags помещение, комната, площадь, зона, room, area, zone, separator
@context arch.room arch.wall_room arch.room_sep arch.zone sel:room
@commands arch.room arch.wall_room arch.room_sep arch.zone ann.tag_all
@see tags_text schedules ceilings

Помещение определяется замкнутым контуром из стен и разделителей и хранит площадь, периметр, объём и название. Площадь пересчитывается при любом изменении стен.

**Пока недоступно:** разделитель помещений (`RS`) и зона (`ZN`). Кнопки этих команд на ленте неактивны.

## steps
1. Наберите `RM` ([[cmd:arch.room]]) или `WR` ([[cmd:arch.wall_room]]): обе рисуют помещение прямоугольником из четырёх стен — щёлкните две противоположные вершины или введите размеры.
2. Разделитель (`RS`, [[cmd:arch.room_sep]]) для свободной планировки запланирован.
3. Любой замкнутый контур можно нарисовать и инструментом «Стена»: `WA`, `C` замыкает контур ([[topic:walls]]).
4. Зона (`ZN`, [[cmd:arch.zone]]), объединяющая помещения для расчётов, запланирована.
5. Пометьте все помещения тегами `TA` ([[cmd:ann.tag_all]]); имя и номер задаются в свойствах.
6. Площади видны в спецификации ([[topic:schedules]]).

## keys
- `RM` / `WR` — помещение прямоугольником стен
- `TA` — пометить все

## tips
- Помещение следует за стенами: сдвинули стену — площадь обновилась.
- При импорте IFC помещения берутся из пространств; незамкнутые получают разделители.
