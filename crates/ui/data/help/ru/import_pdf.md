# PDF как подложка
@tags PDF, подложка, план, масштаб, underlay, scale, trace
@context mgr.import_pdf
@commands mgr.import_pdf mod.measure
@see import_cad units

Страница `.pdf` с планом ложится на уровень подложкой: поверх неё строятся стены. Векторные линии PDF участвуют в привязках.

## steps
1. Запустите `IP` ([[cmd:mgr.import_pdf]]) или выберите `.pdf` в окне «Импорт» (`Ctrl+O`).
2. В окне «Импорт чертежа» выберите уровень, единицы и начало координат.
3. Задайте «Масштаб PDF 1:» (по умолчанию 100): лист масштабируется по этому отношению. Калибровки по двум точкам нет.
4. Нажмите «Разместить». Подложку можно сдвинуть и повернуть в панели «Слои…» (угол, сдвиг).
5. Обводите стены командой `WA`; векторные линии PDF ловятся привязками.
6. Проверьте длины по известному размеру (команда измерения `MS`, [[cmd:mod.measure]], запланирована).

## keys
- `IP` — подложка PDF
- `MS` — измерить

## tips
- PDF с векторными линиями хорошо цепляется привязками; у растрового скана линий для привязки нет.
- Масштаб задаётся только отношением: проверьте его по известному размеру и при необходимости исправьте.
