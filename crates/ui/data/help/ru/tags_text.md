# Марки, текст, выноски, нумерация
@tags марка, текст, выноска, нумерация, tag, text, leader, numbering
@context ann.tag ann.tag_all ann.text ann.number ann.leader
@commands ann.tag ann.tag_all ann.text ann.number ann.leader
@see dimensions rooms_areas schedules

Аннотации подписывают элементы на виде: марка читает параметры элемента (тип, номер, площадь), текст пишется вручную, выноска указывает на элемент.

## steps
1. Марка одного элемента: `TG` ([[cmd:ann.tag]]): щёлкните дверь, окно, стену или помещение; марку можно перетащить за голову, `Delete` удаляет её.
2. Пометить всё: `TA` ([[cmd:ann.tag_all]]): выберите категории; диалог показывает, сколько марок будет добавлено.
3. Нумерация: `NU` ([[cmd:ann.number]]): каждый щелчок ставит элементу следующий номер (+1); один щелчок: один шаг отмены.
4. Свободный текст (`TX`, [[cmd:ann.text]]) и выноска (`LD`, [[cmd:ann.leader]]): щёлкните место, введите несколько строк прямо на виде, `Ctrl+Enter` или щелчок мимо поля подтверждает. Второй щелчок по выбранному тексту снова открывает правку.
5. Текст марки берётся из параметров, меняйте их в свойствах, марка обновится.

## keys
- `TG` марка, `TA` пометить все, `NU` нумерация
- `Delete`: удалить марку под курсором, `Esc`: выход

## tips
- Марка с пустым номером показывает «?».
- Марки принадлежат виду: на другом плане их нужно ставить отдельно.
