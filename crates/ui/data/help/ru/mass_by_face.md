# Элементы по граням формы
@tags по грани, этажи формы, mass floors, by face, wall by face
@context mass.wall_by_face mass.curtain_by_face mass.slab_by_face mass.roof_by_face mass.floors
@commands mass.wall_by_face mass.curtain_by_face mass.slab_by_face mass.roof_by_face mass.floors
@see masses walls floors roofs curtain_walls

Из формы получают настоящие элементы здания: стены и навесные стены по вертикальным граням, перекрытия по горизонтальным, крыши по верхним. Привязка идёт по метке грани, поэтому элементы следуют за формой.

## steps
1. Запустите команду и щёлкните грань формы в 3D.
2. [[cmd:mass.floors]] — «Этажи формы»: сечения формы по уровням, площади этажей считаются сразу.
3. [[cmd:mass.wall_by_face]] — щёлкните вертикальную грань; [[cmd:mass.curtain_by_face]] создаёт навесную стену.
4. [[cmd:mass.slab_by_face]] — щёлкните горизонтальную грань (перекрытие); [[cmd:mass.roof_by_face]] — верхнюю или наклонную грань (крыша).
5. Измените форму (`Push/Pull`, смещение): стены и перекрытия перестроятся.
6. Если грань пропала, элемент останется с предупреждением — перепривяжите его.

## keys
- `Enter` — применить
- `Esc` — выход
- `Ctrl+Z` — отмена, включая каскад привязок

## tips
- При удалении формы привязанные элементы обрабатываются каскадом, отмена возвращает всё.
- Слои стены и перекрытия берутся из выбранного типа: [[topic:wall_layers]].
- Подходит для быстрых вариантов: меняйте форму, не перерисовывая здание.
