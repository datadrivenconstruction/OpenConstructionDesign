# Логические операции с формами
@tags объединить, вычесть, пересечь, булевы, union, subtract, intersect, boolean
@context mass.union mass.subtract mass.intersect mass.join mass.unjoin mass.cut
@commands mass.union mass.subtract mass.intersect mass.join mass.unjoin mass.cut
@see masses mass_by_face

Булевы операции складывают, вычитают и пересекают тела. Результат остаётся редактируемым: исходные формы не пропадают.

## steps
1. Запустите команду и по очереди щёлкайте формы в 3D.
2. Объединение — [[cmd:mass.union]]; вычитание — [[cmd:mass.subtract]] (сначала форма, из которой вычитают, затем вычитаемая); пересечение — [[cmd:mass.intersect]].
3. Для устойчивого соединения геометрии двух элементов: [[cmd:mass.join]]; чтобы разъединить — [[cmd:mass.unjoin]].
4. Подрезать один элемент другим без слияния — [[cmd:mass.cut]] (сначала режущий элемент, затем подрезаемый).
5. Проверьте результат в 3D: грани после операции получают устойчивые идентификаторы.
6. Все операции отменяются одним `Ctrl+Z`.

## keys
- `Ctrl+Z` — отмена
- `Esc` — выход из команды

## tips
- Пустотные формы (`mass.void`) — тот же вычет, но обратимый и параметрический: [[topic:masses]].
- Результаты булевых операций валидируются: некорректное тело не создаётся, причина показана.
- Элементы по граням после операции переносятся на новые грани.
