# Файлы и проекты
@tags файл, проект, создать, открыть, очистка, file, project, purge
@context file.new file.open file.save file.save_as mgr.project_info mgr.purge
@commands file.new file.open file.save file.save_as mgr.project_info mgr.purge
@see autosave import_ifc export

Проект: один файл-база. Здесь основные операции с файлами и служебные команды проекта.

**Пока недоступно:** «Создать» (`Ctrl+N`), «Сохранить» (`Ctrl+S`) и «Сохранить как» (`Ctrl+Shift+S`). Кнопки этих команд на ленте неактивны.

## steps
1. Стартовый экран предлагает «Новая модель» (начать со стены), «Открыть…», «Импорт» и список недавних файлов. `Ctrl+O` ([[cmd:file.open]]) и меню «Файл > Импорт…» открывают окно «Импорт»: `.ifc` / `.ifczip`, `.dxf` / `.dwg`, `.pdf`, `.xlsx`, `.rvt` / `.rfa`.
2. Пока сохранение в файл не подключено, работу защищают снимки автосохранения: [[topic:autosave]].
3. Сведения о проекте (название, адрес, заказчик, организация, подписи, стадия): [[cmd:mgr.project_info]].
4. Очистка: [[cmd:mgr.purge]] (`PU`) удаляет неиспользуемые типы и семейства; одна отмена возвращает всё.
5. Для обмена с другими программами: [[topic:export]]; для чужих файлов: [[topic:import_ifc]], [[topic:import_rvt]].

## keys
- `Ctrl+O`: открыть / импорт
- `Ctrl+Z`: отменить

## tips
- Проект: один файл базы данных; копии храните отдельно.
- Образец дома: [[cmd:help.sample]].
