# Импорт IFC
@tags IFC, IFCZIP, импорт, обмен, import, exchange
@commands file.open mgr.links data.export_ifc
@see import_rvt export linked_models

IFC: открытый формат обмена. Редактор читает IFC2X3, IFC4X1/X2/X3 и архивы IFCZIP. Любой продукт с геометрией становится родным элементом или редактируемой сеткой (mesh).

## steps
1. Откройте файл через `Ctrl+O` ([[cmd:file.open]]) или «Файл > Импорт…» и выберите `.ifc` или `.ifczip`.
2. Файл импортируется целиком одной операцией (один `Ctrl+Z` отменяет её); отчёт в окне «Импорт» перечисляет созданное.
3. В отчёте указаны уровни, стены, проёмы, перекрытия, помещения, оси, навесные стены и компоненты; не перенесённые виды перечислены строками «не перенесено: вид ×N».
4. Если в файле нет уровней, создаётся уровень по умолчанию. Повторный импорт в этой сборке элементы не обновляет.
5. Просмотрите отчёт и окно предупреждений ([[topic:warnings]]).
6. Подключение IFC как связанной модели запланировано: [[topic:linked_models]].

## keys
- `Ctrl+O`: открыть / импорт
