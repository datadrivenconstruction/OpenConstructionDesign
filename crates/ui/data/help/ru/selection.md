# Выбор элементов
@tags выбор, выделение, рамка, фильтр, select, selection, filter
@context edit.select_all mod.select_same_cat mod.select_same_cat_project mod.select_similar_project
@commands edit.select_all mod.select_same_cat mod.select_same_cat_project mod.select_similar_project mod.select_similar mod.select_filter
@see query_bulk modify visibility

Выбор это исходное состояние редактора: любое действие начинается с выбранных элементов. У выбранного сразу появляются ручки и временные размеры, отдельного режима правки нет.

## steps
1. Щёлкните элемент. Щелчок в пустоте снимает выбор.
2. `Ctrl`+щелчок добавляет элемент к выбору; `Shift`+щелчок исключает элемент из выбора. Рамка: слева направо: только полностью внутри (секущая рамка), справа налево: всё, чего она касается (пересекающая).
3. `Tab` над курсором перебирает кандидатов под ним.
4. Выделите всё на виде: `Ctrl+A` ([[cmd:edit.select_all]]).
5. Расширьте выбор: [[cmd:mod.select_same_cat]] (та же категория на виде) или [[cmd:mod.select_same_cat_project]] (во всём проекте).
6. Сузьте выбор фильтром ([[cmd:mod.select_filter]], `SX`): по категориям, закреплённым, связям.
7. Состав выбора виден в строке состояния.

## keys
- `Ctrl` + щелчок: добавить
- `Ctrl` + рамка: добавить, `Shift` + щелчок: исключить
- `Tab`: следующий кандидат
- `Ctrl+A`: выбрать всё на виде
- `Ctrl+Shift+A`: выбрать похожие
- `Esc`: снять выбор

## tips
- Выбранный элемент перемещается за ручки; копирование: командой копирования.
- Для условий вроде «двери шире 900» используйте запрос ([[topic:query_bulk]]).
