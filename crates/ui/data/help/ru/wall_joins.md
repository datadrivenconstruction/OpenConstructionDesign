# Стыки стен (L, T, X)
@tags стыки, углы, соединение, пересечение, join, corner, miter, butt
@context mod.join
@commands mod.join mod.wall_edit mod.cut_geom
@see walls wall_layers wall_profile

Где стены сходятся, редактор сам строит стык: угловой (L), примыкание (T) и пересечение (X), включая узлы из трёх и более стен. Слои продолжаются по приоритету, а проёмы и срезы пересчитываются.

**Пока недоступно:** ручное соединение (`JN`) и подрезка геометрии (`mod.cut_geom`). Кнопки этих команд на ленте неактивны.

## steps
1. Нарисуйте стены так, чтобы концы касались: стык создаётся автоматически.
2. Чтобы изменить вариант соединения, выберите стену и запустите [[cmd:mod.wall_edit]]: на каждом узле появится значок.
3. Щелчок по значку переключает соединение: встык, под углом (косой срез), прямой срез. `Shift`+щелчок разрешает или запрещает соединение в узле (на значке крест).
4. Та же панель правит слои, вертикальную структуру и проёмы: [[topic:wall_layers]].
5. Ручное соединение и разъединение элементов (`JN`, [[cmd:mod.join]]) запланированы.
6. Очистка по приоритету слоёв: стена с более «сильным» слоем проходит сквозь остальные.

## keys
- Щелчок по значку — следующий вариант соединения, `Shift`+щелчок — разрешить / запретить

## tips
- Каждое переключение варианта — отдельный шаг отмены.
- Узел из трёх и более стен строится по реальным телам слоёв, а не по осям.
