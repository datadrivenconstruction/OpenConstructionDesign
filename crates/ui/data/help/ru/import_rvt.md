# Импорт .rvt и .rfa
@tags rvt, rfa, импорт, открыть, профессиональные BIM-программы, import
@commands file.open mgr.links mgr.purge
@see import_ifc linked_models big_files

Файлы `.rvt` (модель) и `.rfa` (семейство) открываются через окно «Импорт» отдельным подписанным модулем `.rvt` / `.rfa`. Если модуль не установлен, окно сообщает об этом, а формат остаётся недоступным.

## steps
1. Выберите «Открыть» (`Ctrl+O`, [[cmd:file.open]]) и укажите файл `.rvt`.
2. Окно «Импорт» показывает, доступен ли модуль («.rvt/.rfa: доступно» или причину недоступности).
3. Загрузка идёт в фоне: интерфейс доступен, индикатор и кнопка «Отмена»: в окне «Импорт». Одновременно идёт только один импорт.
4. Проверьте результат в 3D и сверьте с исходником. Замечания собираются в окне предупреждений ([[topic:warnings]]).
5. Сохранение как проекта редактора (`Ctrl+Shift+S`) в этой сборке не подключено; работу защищает автосохранение ([[topic:autosave]]).
6. Семейства `.rfa` читает тот же модуль, они попадают в библиотеку: [[topic:families]].

## keys
- `Ctrl+O`: открыть
- «Отмена» в окне «Импорт» останавливает загрузку

## tips
- Подключение исходника как связанной модели запланировано ([[topic:linked_models]]).
- Для больших файлов используйте секущий бокс и изоляцию ([[topic:big_files]]).
- Не поддержанное содержимое не теряется молча: оно перечисляется в предупреждениях.
