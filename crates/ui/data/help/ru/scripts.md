# Скрипты и запись действий
@tags скрипт, автоматизация, узлы, запись, script, automation, macro
@context mgr.scripts mgr.record
@commands mgr.scripts mgr.record data.query
@see query_bulk command_palette

Скрипт — файл правок: JSON-конверт на языке правок, которым пользуются инструменты, импорт из XLSX и ассистент. В нём заголовок и группы операций (создать, изменить, удалить). Скрипты лежат в папке scripts каталога настроек; путь к ней показан в окне.

## steps
1. Нажмите `SR` ([[cmd:mgr.scripts]]) — скрипты папки показаны списком по имени.
2. Чтобы добавить скрипт, нажмите «Добавить скрипт» и выберите файл `.json`: он проверяется и копируется в папку (существующий скрипт не перезаписывается).
3. Выберите скрипт: видны его заголовок и группы с числом операций; если файл не читается, окно скажет почему.
4. «Просмотр» — пробный прогон на копии модели: сколько элементов скрипт создаст, изменит и удалит. Модель не меняется.
5. «Выполнить» применяет скрипт; если какая-то операция отклонена, ничего не меняется и показана причина.
6. Массовые правки по условию проще делать запросом: [[topic:query_bulk]].

## keys
- `SR` — скрипты
- `Ctrl+Z` — отменить последний запуск скрипта
- `Ctrl+K` — палитра

## tips
- Один запуск скрипта — одна запись в истории, `Ctrl+Z` откатит его целиком.
- История изменений называет скрипт автором его правок.
- Неизвестные поля и конверты более новой версии отклоняются, поэтому опечатка не выполнит скрипт наполовину.
