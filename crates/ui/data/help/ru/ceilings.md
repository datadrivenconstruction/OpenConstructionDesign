# Потолки
@tags потолок, подвесной, ceiling, opening
@context arch.ceiling arch.ceiling_opening
@commands arch.ceiling arch.ceiling_opening
@see rooms_areas floors openings_shafts

Потолок: плоский слоистый элемент на заданной высоте над уровнем. Обычно строится по контуру помещения.

## steps
1. Наберите `CG` ([[cmd:arch.ceiling]]).
2. Щёлкните внутри замкнутого контура стен (контур берётся автоматически, контур под курсором подсвечен) или нарисуйте контур по точкам; щелчок рядом с первой точкой замыкает его.
3. В панели опций выберите тип потолка и высоту над уровнем (по умолчанию 2,7 м).
4. Нарисованный вручную контур завершается `Enter` (не меньше 3 точек).
5. Отверстие в потолке (под люк, светильник, шахту): [[cmd:arch.ceiling_opening]]: нарисуйте контур.
6. Проверьте потолок в разрезе: он отображается на своей высоте.

## keys
- `CG`: потолок
- `Enter`: завершить; `Esc`: сбросить введённые точки, повторное `Esc`: выход
- `Backspace`: убрать последнюю точку
- `Ctrl+Z`: отмена

## tips
- Шахта автоматически прорезает потолки на своём пути ([[topic:openings_shafts]]).
- Высоту потолка меняйте в свойствах: для нескольких сразу выберите и измените общее значение.
