# Тяжёлые модели
@tags большие файлы, производительность, тормозит, LOD, performance, large model
@commands view.section_box mod.isolate view.hide_cat view.detail_level mgr.purge
@see section_box visibility views_3d import_rvt

Большие модели открываются в фоне и остаются отзывчивыми, если ограничивать то, что рисуется. Основные приёмы: изоляция, секущий бокс, скрытие категорий, уровень детализации.

**Пока недоступно:** скрытие категории в плане, уровень детализации и «Очистить неиспользуемое». Кнопки этих команд на ленте неактивны.

## steps
1. Файл `.rvt` или `.ifc` загружается через окно «Импорт» ([[topic:import_rvt]], [[topic:import_ifc]]); загрузка `.rvt` идёт в фоне, в окне есть индикатор и кнопка «Отмена».
2. В 3D ограничьте сцену секущим боксом вокруг уровня или зоны: `BX` ([[cmd:view.section_box]]).
3. Изолируйте нужное: `HI` ([[cmd:mod.isolate]]); скрытие целой категории: [[cmd:view.hide_cat]].
4. Снижение уровня детализации вида ([[cmd:view.detail_level]]) запланировано.
5. Удаление неиспользуемых типов и семейств: [[cmd:mgr.purge]].

6. Большой файл модели можно открыть в фоне: [[cmd:mgr.open_big]]; кэш сеток ([[cmd:mgr.mesh_cache]]) ускоряет 3D для импортных сеток. В 3D категорию можно временно скрыть: [[cmd:view.hide_cat_3d]].

## keys
- `BX`: секущий бокс, `HI`: изолировать, `HC`: скрыть категорию
- `HR`: показать всё

## tips
- Работайте в плане нужного уровня, а 3D используйте только для проверки.
- Импортируйте большой `.rvt` или `.ifc` по частям: сначала нужные уровни ([[topic:import_rvt]]).
- С секущим боксом сцена рисуется только внутри бокса: чем меньше бокс, тем быстрее кадр.
