# Семейства, типы и библиотека
@tags семейство, тип, типоразмер, библиотека, .rfa, family, type, library
@context mgr.library mgr.load mgr.types mod.change_type
@commands mgr.library mgr.load mgr.types mgr.params mod.change_type
@see components parameters wall_layers

Семейство — шаблон элемента, тип — его набор размеров и параметров. Библиотека хранит семейства; в проект загружаются только нужные.

**Пока недоступно:** загрузка семейства в проект (`mgr.load`). Кнопки этих команд на ленте неактивны.

## steps
1. Откройте [[cmd:mgr.library]] — «Библиотека компонентов»: поиск и семейства по категориям (мебель, двери, окна, сантехника, освещение, оборудование…).
2. Выберите семейство в списке; семейства `.rfa` из файлов читает установленный модуль `.rvt` / `.rfa` ([[topic:import_rvt]]).
3. Типами управляйте в [[cmd:mgr.types]] (`TY`): создавайте, дублируйте, переименовывайте, правьте параметры.
4. Параметры типа редактируются в окне параметров ([[cmd:mgr.params]], `PA`); все экземпляры типа обновляются разом.
5. Чтобы сменить тип у выбранных элементов, нажмите `CY` ([[cmd:mod.change_type]]) — одна операция, один `Ctrl+Z`.
6. Удаление неиспользуемых типов («Очистить неиспользуемое») запланировано: [[topic:files_projects]].

## keys
- `TY` — менеджер типов
- `PA` — параметры семейства
- `CY` — сменить тип
- `Ctrl+Z` — отмена

## tips
- Редактор параметров пишет только значения типов; формулы и значения по умолчанию внутри семейства здесь не меняются.
- Слои стен, перекрытий и сечения стержней — тоже типы: [[topic:wall_layers]].
- Параметры, общие для всего проекта: [[topic:parameters]].
