# Параметры
@tags параметры, свойства, параметры проекта, parameters, properties, project parameters
@context mgr.params mgr.project_params
@commands mgr.params mgr.project_params mgr.types
@see families query_bulk schedules

Параметры хранят данные элементов: размеры, материалы, марки. Параметры семейства относятся к типу; параметры проекта добавляют общие поля сразу многим категориям.

## steps
1. Выберите элемент — панель свойств показывает его параметры, разделённые на экземплярные и типа.
2. Параметры типа правятся в окне [[cmd:mgr.params]] (`PA`): изменение касается всех элементов типа.
3. Общий параметр для категорий (например, «Огнестойкость»): [[cmd:mgr.project_params]] (`PJ`) — имя, тип данных, категории.
4. Новый параметр сразу доступен в спецификациях, фильтрах и запросах.
5. Заполняйте значения в свойствах, в спецификации или массово через `.xlsx` ([[topic:xlsx_sync]]).
6. Для условий и групповой правки используйте [[topic:query_bulk]].

## keys
- `PA` — параметры семейства, `PJ` — параметры проекта
- `Ctrl+Z` — отмена

## tips
- Тип данных (число, длина, текст, да/нет) задайте сразу: потом сменить сложнее.
- Правка типа — одна операция отмены.
