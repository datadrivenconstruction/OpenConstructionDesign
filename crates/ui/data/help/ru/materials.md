# Материалы и стили объектов
@tags материал, стиль объектов, цвет, штриховка, material, object styles, color
@context mgr.materials mgr.object_styles
@commands mgr.materials mgr.object_styles view.filters
@see wall_layers visibility

Материал задаёт цвет и узор слоя; стиль объекта — линии и заливку категории на видах.

**Пока недоступно:** список материалов (`mgr.materials`), стили объектов (`mgr.object_styles`) и фильтры видимости (`VV`). Кнопки этих команд на ленте неактивны.

## steps
1. Список материалов проекта ([[cmd:mgr.materials]]) запланирован; сейчас материалы назначаются через слои типа ([[topic:wall_layers]]).
2. Назначьте материал слою в типе ([[topic:wall_layers]]).
3. Веса линий и цвета по категориям ([[cmd:mgr.object_styles]]) запланированы.
4. Фильтры видимости ([[cmd:view.filters]]) запланированы.
5. Граням форм материалы назначаются командой «Покрасить» ([[cmd:mass.paint]]).
6. Проверьте результат в плане, разрезе и 3D: штриховка зависит от масштаба.

## keys
- `Ctrl+Z` — отмена

## tips
- Один материал — много слоёв: меняется в одном месте.
