# Импорт DWG и DXF
@tags DWG, DXF, чертёж, подложка, импорт, CAD, import, drawing
@context mgr.import_cad
@commands mgr.import_cad mgr.import_pdf mod.measure
@see import_pdf units levels

Файл `.dwg` или `.dxf` ложится на уровень подложкой: поверх него строятся стены и оси. Блоки (INSERT) раскрываются; DXF читается начиная с R2000.

## steps
1. Запустите `IC` ([[cmd:mgr.import_cad]]) или `Ctrl+O` — откроется окно «Импорт»; выберите файл (можно сразу несколько, каждый — на свой или на новый уровень).
2. В окне «Импорт чертежа» задайте единицы (авто из файла, мм, см, м, дюйм, фут): при несовпадении всё окажется в сотни раз больше или меньше.
3. Выберите начало: как в файле, левый нижний угол в (0, 0) или выравнивание по первому чертежу; при необходимости задайте сдвиг X / Y в метрах и нажмите «Разместить».
4. Сверьте известный размер с подложкой (команда измерения `MS`, [[cmd:mod.measure]], запланирована), чтобы убедиться в масштабе.
5. Стены (`WA`) и оси (`GR`) стройте поверх подложки; привязки работают к её линиям. В панели «Слои…» есть режим обводки: щелчок по линии даёт стену текущего типа.
6. Панель «Слои…» включает и выключает чертёж и его слои, делает их полутоном, перемещает / поворачивает / копирует чертёж и убирает его.

## keys
- `IC` — импорт DWG/DXF
- `IC` — импорт DWG/DXF (повторно)
- `Tab` — перебор привязок, включая линии подложки

## tips
- При единицах «авто» масштаб берётся из заголовка файла; проверьте его по известному размеру.
- Окно «Чертёж → BIM…» распознаёт стены и другие элементы по чертежу, с предпросмотром и правилами для блоков.
- Растровую или векторную страницу `.pdf` подкладывают отдельно: [[topic:import_pdf]].
