# Обмен с таблицами .xlsx
@tags xlsx, таблицы, импорт, экспорт, предпросмотр, spreadsheet, round-trip, import
@context data.import_xlsx data.export_xlsx
@commands data.import_xlsx data.export_xlsx view.schedule
@see schedules query_bulk undo_history

Модель можно выгрузить в `.xlsx`, поправить в любой программе для электронных таблиц и вернуть обратно. Перед применением показывается предпросмотр изменений, а весь импорт откатывается одним `Ctrl+Z`.

## steps
1. Выгрузка: `Ctrl+E` ([[cmd:data.export_xlsx]]), вкладка «Данные» или меню «Файл > Экспорт в XLSX…», выберите файл (по умолчанию предлагается рядом с проектом, под его именем); модель записывается по категориям.
2. Правьте значения в файле. Новые строки создают элементы, удалённые могут удалять, изменённые значения правят элементы.
3. Единицы можно указать в заголовке столбца: `m`, `mm`, `cm`, `ft`, `in`, `ft-in`.
4. Загрузка: «Файл > Импорт из XLSX…» или `.xlsx` в окне «Импорт». Адреса вида `Лист!A1` распознаются.
5. Просмотрите предпросмотр: счётчики добавленных, изменённых и удалённых строк, новые столбцы, ошибки (фильтр «Только ошибки»). Пока не нажато «Применить», модель не меняется.
6. Нажмите «Применить». Результат это одна операция: `Ctrl+Z` отменяет всё. «Файл > Синхронизировать с XLSX» перечитывает связанную книгу и показывает расхождения.

## keys
- `Ctrl+E`: выгрузить в XLSX
- `Ctrl+Z`: откатить весь импорт
- Меню «Файл» (имя проекта, `Alt+F`): выгрузка, загрузка, синхронизация

## tips
- Не меняйте столбец идентификатора: по нему строки сопоставляются с элементами.
- На очень больших таблицах (десятки тысяч строк) импорт может занять секунды: пересчитываются количества.
