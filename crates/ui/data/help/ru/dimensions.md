# Размеры
@tags размер, размеры, отметка, временный размер, dimension, spot elevation, measure
@context ann.dim ann.dim_angular ann.dim_radial ann.spot_elev ann.dim_auto mod.measure
@commands ann.dim ann.dim_angular ann.dim_radial ann.spot_elev ann.dim_auto mod.measure
@see tags_text units snaps

Размеры бывают постоянные (аннотация вида) и временные (видны при построении или выборе элемента); число во временном размере можно править.

**Пока недоступно:** высотная отметка (`SE`) и измерение (`MS`). Кнопки этих команд на ленте неактивны.

## steps
1. Линейный размер: `DI` ([[cmd:ann.dim]]) — щёлкайте опоры по очереди (`Tab` переключает ось / грань), затем щёлкните в пустом месте, чтобы поставить размерную линию.
2. Автоцепочка вдоль стены: `AD` ([[cmd:ann.dim_auto]]) — выберите стену, чтобы получить проёмы и простенки. Одна стена продолжается на соосные стены, которых касается; несколько выбранных стен дают по цепочке на каждую касающуюся соосную группу. Дуговые стены пропускаются, в строке состояния показано их число.
3. Угол между двумя стенами — `DA` ([[cmd:ann.dim_angular]]), радиус дуговой стены — `DR` ([[cmd:ann.dim_radial]]).
4. Высотная отметка — `SE` ([[cmd:ann.spot_elev]]).
5. Измерение расстояния без создания размера — `MS` ([[cmd:mod.measure]]).
6. Чтобы изменить значение временного размера, щёлкните по числу и введите новое.

## keys
- `DI` `DA` `DR` — линейный, угловой, радиальный размер
- `AD` — цепочка по стене, `SE` — отметка
- `MS` — измерить
- `Tab` — переключить ось / грань при выборе опоры

## tips
- Единицы и точность — в [[topic:units]]; можно вводить `3500`, `3.5m`, `12'6"`.
- Размеры цепляются за оси и грани стен: переключайте их `Tab`.
- Временные размеры показывают расстояния до соседних стен и осей при установке элемента.
