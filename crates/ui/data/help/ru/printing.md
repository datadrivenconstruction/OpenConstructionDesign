# Печать и PDF
@tags печать, PDF, SVG, набор листов, print, pdf, svg, sheet set
@context view.print_sheets data.export_pdf
@commands view.print_sheets data.export_pdf view.sheet_set
@see sheets export

Листы выводятся в векторные файлы PDF (и по желанию DXF): линии остаются линиями, текст: текстом, веса линий следуют настройкам. Печати на принтер и вывода в SVG нет.

## steps
1. Подготовьте листы ([[topic:sheets]]) и при необходимости набор: [[cmd:view.sheet_set]].
2. Откройте окно «Печать листов»: [[cmd:view.print_sheets]] или кнопка «Печать…» на листе; выберите диапазон: текущий лист, все, выбранные или набор.
3. `XP` ([[cmd:data.export_pdf]]) открывает то же окно.
4. Задайте бумагу («как на листе» или формат, книжная / альбомная) и вывод: один PDF со страницей на лист либо отдельный PDF на каждый лист, по желанию ещё DXF на каждый лист; укажите имя файла.
5. Запустите вывод; окно сообщает о числе записанных листов.
6. Откройте результат из папки и сверьте первый лист.

## keys
- `XP`: экспорт PDF/SVG

## tips
- Набор листов можно выводить сколько угодно раз, весь выпуск за одно действие.
- Поддерживаются форматы A0-A4 и ANSI A-E.
- Для передачи модели (а не чертежей) используйте [[topic:export]].
- Справа в окне печати виден предпросмотр каждой страницы. Можно выпускать только DXF, сняв галочку PDF.
- Печать идёт в фоне, с полосой хода и кнопкой остановки. Сбой одного листа не останавливает набор: в отчёте указаны лист и причина. Перед печатью в папку окно показывает файлы, которые будут заменены, и просит подтвердить.
