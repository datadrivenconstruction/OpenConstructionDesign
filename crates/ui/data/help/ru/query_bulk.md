# Запрос и массовая правка
@tags запрос, поиск, фильтр, массовая правка, query, bulk edit, filter
@context data.query mod.select_filter mod.select_similar
@commands data.query mod.select_filter mod.select_similar mod.select_same_cat_project
@see selection parameters xlsx_sync

Запрос ищет элементы по категории и условиям и может изменить найденное одной операцией. Поле запроса находится в палитре `Ctrl+K`; тот же механизм доступен командой [[cmd:data.query]] (`QY`).

Окно [[cmd:data.query]] (`QY`) читает запрос по мере ввода: число найденного и сводку по категориям или ошибку простыми словами. Главная кнопка выделяет результат или, с `->`, изменяет его одной операцией; правильный запрос можно сохранить как фильтр проекта, а щелчок по сохранённому фильтру выделяет то, что он находит.

## steps
1. Нажмите `Ctrl+K` и введите запрос: `двери ширина>900` или `стены тип=Кладка 200 уровень=2`.
2. Условия можно соединять словами `и`, `или`, `не` и скобками: `окна или двери`.
3. Результат показывает число найденных элементов; выберите строку, чтобы выделить их на виде.
4. Для массовой правки добавьте `->`: `двери ширина>900 -> ширина=ширина+100`.
5. Применённая правка это одна операция: `Ctrl+Z` откатывает её целиком.
6. Частые запросы сохраните как фильтры проекта; «выбрать похожие»: `Ctrl+Shift+A` ([[cmd:mod.select_similar]]).

## keys
- `Ctrl+K`: палитра с запросом
- `Enter`: выполнить, `Esc`: закрыть

## tips
- Есть операторы `=`, `<>`, `<`, `>`, `<=`, `>=`, `~` (содержит). Слово без оператора ищет в типе, имени и марке.
- В английском интерфейсе ключевые слова тоже английские: `doors width>900 -> width=width+100`.
- Длины без единицы понимаются в единицах проекта; можно писать `1.2m`.
