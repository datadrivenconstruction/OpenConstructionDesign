# Палитра команд и поиск
@tags палитра, поиск, команда, где находится, palette, search, find, where is
@context app.palette app.where_is app.find
@commands app.palette app.where_is app.find app.repeat
@see shortcuts query_bulk interface

Палитра `Ctrl+K` находит всё: команды, виды, уровни, элементы, параметры и запросы. Она показывает путь в ленте и клавишу каждой команды.

**Пока недоступно:** повтор последней команды. Её кнопка на ленте неактивна.

## steps
1. Нажмите `Ctrl+K` ([[cmd:app.palette]]) или щёлкните по полю поиска в верхней панели и начните вводить название: достаточно любого слова.
2. Стрелками выберите результат, `Enter` — выполнить. Команда запускается с текущим выбором.
3. Запрос вроде `двери ширина>900` показывает элементы, а `->` меняет их ([[topic:query_bulk]]).
4. `Ctrl+Shift+K` ([[cmd:app.where_is]]) — «Где находится…»: опишите привычное понятие своими словами, и редактор покажет нашу команду.
5. `Ctrl+F` ([[cmd:app.find]]) открывает окно поиска в поле «Найти»; `Ctrl+H` ([[cmd:edit.find_replace]]) добавляет строку замены. «Выделить все найденные» выделяет найденные элементы. Элементы, виды и параметры по названию ищите в этой палитре.
6. Повторить последнюю команду — [[cmd:app.repeat]].

## keys
- `Ctrl+K` — палитра
- `Ctrl+Shift+K` — «Где находится…»
- `Ctrl+F` — найти текст
- `Ctrl+H` — найти и заменить текст
- `Ctrl+P` — перейти к виду

## tips
- В палитре также есть элементы, виды, уровни и сохранённые фильтры проекта.
- Недавно использованные команды показаны первыми.
