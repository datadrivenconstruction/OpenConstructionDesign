# Лестницы, ограждения, пандусы
@tags лестница, ограждение, перила, пандус, stair, railing, ramp
@context arch.stair arch.railing arch.ramp
@commands arch.stair arch.railing arch.ramp
@see levels floors openings_shafts

Лестница соединяет два уровня; ограждения строятся по маршу и площадке, пандус — наклонная поверхность с заданным уклоном.

**Пока недоступно:** пандус (`RA`). Кнопки этих команд на ленте неактивны.

## steps
1. Наберите `ST` ([[cmd:arch.stair]]), щёлкните начало марша и затем его конец; в превью видно «N подъёмов из M».
2. В панели опций задайте нижний и верхний уровни, ширину и линию привязки (центр / лево / право); «Ограждение авто» строит ограждение по обоим краям тем же действием.
3. Число подъёмов считается по высоте между уровнями; проступь — 0,28 м.
4. Отдельное ограждение — `RL` ([[cmd:arch.railing]]): щёлкайте точки пути и нажмите `Enter` либо выберите «Выбрать основу» и щёлкните по лестнице.
5. Пандус (`RA`, [[cmd:arch.ramp]]) запланирован.
6. Отверстие в перекрытии над лестницей вырезайте шахтой `SH` ([[topic:openings_shafts]]).

## keys
- `ST` — лестница, `RL` — ограждение
- `Enter` — завершить путь ограждения, `Esc` — выход

## tips
- Сначала создайте уровни: лестница соединяет два существующих уровня ([[topic:levels]]).
