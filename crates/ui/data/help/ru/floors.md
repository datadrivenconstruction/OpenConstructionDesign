# Перекрытия
@tags перекрытие, плита, пол, floor, slab, layers
@context arch.floor str.slab sel:floor
@commands arch.floor str.slab ctx.floor.shape mass.slab_by_face
@see shape_edit openings_shafts roofs

Перекрытие — слоистый элемент с контуром, толщиной и типом. Архитектурное перекрытие создаётся командой `FL`, несущее перекрытие — `SB`.

## steps
1. Наберите `FL` ([[cmd:arch.floor]]) или `SB` ([[cmd:str.slab]]).
2. Щёлкните внутри замкнутого контура стен — контур берётся автоматически. `Space` переключает: по осям / по внутренним граням (предпросмотр показывает площадь).
3. Либо нарисуйте контур точками, вводя длины числом.
4. Выберите тип и уровень в панели опций; смещение по высоте задаётся в свойствах.
5. Завершите `Enter`; перекрытие появляется во всех видах и в количествах.
6. Существующие перекрытия (из примера, IFC или формы) правятся по [[topic:shape_edit]].

## keys
- `FL` — перекрытие, `SB` — несущее перекрытие
- `Space` — по осям / по граням
- `Enter` — завершить, `Esc` — выход
- `Backspace` — убрать последнюю точку

## tips
- Проёмы в перекрытии — [[topic:openings_shafts]]; шахты режут все перекрытия, которые пересекают.
- Перекрытие по грани формы — [[cmd:mass.slab_by_face]] ([[topic:mass_by_face]]).
