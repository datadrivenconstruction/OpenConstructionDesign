# Отмена и история
@tags отмена, повтор, история, журнал, undo, redo, history
@context edit.undo edit.redo app.history
@commands edit.undo edit.redo app.history
@see autosave modify

Любое действие записывается в журнал модели: один жест — одна запись. Отмена и повтор работают без ограничения числа шагов, а закоммиченное не теряется.

**Пока недоступно:** окно истории (`Ctrl+Shift+H`) с возвратом к выбранному состоянию. Кнопки этих команд на ленте неактивны.

## steps
1. `Ctrl+Z` ([[cmd:edit.undo]]) — отменить; `Ctrl+Y` или `Ctrl+Shift+Z` ([[cmd:edit.redo]]) — повторить.
2. Внутри незавершённого действия `Ctrl+Z` сбрасывает весь черновик (введённые точки), журнал не затрагивается; `Backspace` стирает только набранную цифру.
3. Если отменять нечего, строка состояния сообщает об этом.
4. Каждая завершённая операция — один шаг отмены, в том числе массовая.
5. Импорт `.xlsx`, смена типа и запрос с `->` отменяются одним шагом.
6. Сохранение и автосохранение: [[topic:autosave]].

## keys
- `Ctrl+Z` — отмена, `Ctrl+Y` / `Ctrl+Shift+Z` — повтор
- `Backspace` — стереть набранную цифру (элементы не удаляет)

## tips
- Новое действие после отмены сбрасывает ветку повтора.
- Удалённое всегда можно вернуть отменой; файлы пользователя редактор не удаляет сам.
