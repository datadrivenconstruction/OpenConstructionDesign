# id | routes | sel | undo | active | exec | note
# routes: P palette + registry surfaces (R ribbon, C context bar, M radial, A app bar, D browser, ...).
# sel: "-" none, "*" any, else selection categories; a selection command run with nothing
#   selected must change nothing and push no undo step.
# undo: undo steps one run adds (0, 1, "?" = at most one). active: tool | once | ?.
# exec: run = scripted headless run with oracles; todo = handler not scripted yet (counted);
#   skip = never run headless (reason in note). Commands without a handler are always run:
#   they must refuse in words and change nothing.
