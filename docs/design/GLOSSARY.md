## Подписи и тексты

- Регистр: только первое слово с заглавной (sentence case), после двоеточия строчная.
- Лента: ≤2 значимых слова (предлоги не считаются); для длинных подписей ключ `cmd.<id>.short`.
- Подсказка: `cmd.<id>.desc`: что делает и как применить, ≤150 знаков, с точкой.
  Клавиши не повторять: лента сама рисует сочетание и мнемонику.
- Строка состояния: `hint.<tool>.<step>`, вида «Инструмент: укажите … · клавиша, тире, действие ·
  Esc, тире, отмена». Разделитель « · », не «;».
- Ошибка/предупреждение: что случилось и что сделать (проём вышел бы за пределы основы,
  сдвиньте его внутрь стены). Без id элементов и английских фрагментов (`app/src/ui_err.rs`).
- Пустое состояние: `empty.<что>.title` + `empty.<что>.hint` (`ui_kit::empty_state`).
- Кавычки «ёлочки», тире с пробелами по обе стороны, многоточие одним символом «…», буква «ё» пишется.

## Проверяется тестом

Раздел читает `crates/ui/tests/wording_lint.rs`; правьте таблицы здесь, а не в тесте. Остальные правила
теста (регистр, «…», точка, тире с пробелами, «X: глагол», длина ru) описаны в самом тесте.

Названия функции ИИ: «ИИ-помощник / AI assistant»; в командах глагол первым («Спросить ИИ / Ask AI»);
окно «Настройки ИИ / AI settings». Вкладка ленты «Изменить / Modify», слово «Правка» именем не
служит. Подписи без сокращений: «Синхр.», «Пл.», «исх.» запрещены.

### Не писать

Совпадение ищется с начала слова, без учёта регистра (так «ведомост» ловит все формы). Исключения:
вариант без строчных букв («AI», «ИИ: ») сверяется с учётом регистра; префикс `^` значит: только в начале
строки (подпись команды «X: глагол», а не «Модель ИИ: …»); префикс `@` значит: только в подписях команд,
групп, вкладок и кнопок. Фразы из столбца «писать» перед проверкой вырезаются из строки.
